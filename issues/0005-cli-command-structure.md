# 0005: CLIのコマンド構造整備

`cmd/furumai/main.go` は現在 `os.Args[1]` を手書きの switch で分岐している
だけで、サブコマンドが増える（`test` 等）と破綻する。今後コマンドが
増えることを見越して、コマンド構造を整理する。

## やること

- 標準の `flag.NewFlagSet` によるサブコマンドパターンに寄せる
  （cobra等のサードパーティ依存は、現時点のコマンド数に対しては過剰
  なので採用しない）
- サブコマンドごとに独立した関数として実装し、追加しやすい形にする
- 既存の `version`/`help` コマンドを新しい構造に載せ替える
- 不明なサブコマンド・引数不足時のエラーメッセージと終了コードを整理する

## 制約

- サードパーティのCLIライブラリは導入しない
- 新しいサブコマンド自体（`test`等）の実装は別タスクで扱う

## Definition of Done

- `version`/`help` が新しい構造で動作する
- サブコマンドを追加する際の実装パターンが明確になっている
