# Security Policy

## Reporting a Vulnerability

If you find a security vulnerability in furumai, please report it
privately rather than opening a public issue: use GitHub's
[private vulnerability reporting](https://github.com/ningenMe/furumai/security/advisories/new)
for this repository.

Please don't disclose the issue publicly until a fix has been released.

## Supported Versions

furumai is pre-1.0 and under active development. Only the latest commit
on `main` is supported; there are no maintained release branches.
